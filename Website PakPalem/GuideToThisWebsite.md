# Assistant Working Style

When continuing this project in a future chat:

- Preserve the existing visual identity.
- Reuse `style.css` and `service.css`; extend them instead of rewriting them.
- Keep all pages responsive and mobile-friendly.
- Use semantic HTML5 and modular CSS.
- Maintain the premium dark theme with lime-green accents.
- Use Font Awesome icons and Poppins typography.
- Favor reusable components over page-specific styles.
- When adding new pages or sections, follow the established spacing, card styles, button styles, and typography for consistency.
